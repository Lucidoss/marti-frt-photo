# Martin Frontera — Photographie

Portfolio photo, Jard-sur-Mer (Vendée). Site statique : HTML, CSS, JS — GSAP + ScrollTrigger + Lenis.

- **Photos** : `photos/NN.jpg` (2400 px) et `photos/thumb/NN.jpg` (900 px), décrites dans le tableau `PHOTOS` en haut de `main.js`.
- **Lancer en local** : `python -m http.server 5173` puis http://localhost:5173
- **En ligne** : GitHub Pages, depuis la branche `main`.
